Espace / Bot

Bot Discord

Ajoute le bot 2KR sur ton propre serveur : il installe les rôles, les salons et le règlement au style du site.

🤖 Ajouter le bot à mon serveur
Comment l'utiliser
1. Clique sur « Ajouter » et choisis ton serveur (il faut la permission « Gérer le serveur »).
2. Le bot demande la permission Administrateur : elle lui sert à créer les rôles et les salons.
3. Dans ton serveur, tape /setup (réservé aux administrateurs) : tout est installé.
4. /dispo pseudo vérifie si un pseudo est libre.
5. Les nouveaux arrivants reçoivent automatiquement le rôle Membre et un message de bienvenue.
Espace / Admin

Admin

Tout ce que tu fais ici apparaît en direct chez tout le monde.

Tu es admin délégué : tu gères les utilisateurs, les rôles et les clés. Les réglages généraux (texte, verrouillage, serveur, Client ID) et les comptes admin restent réservés à l’admin principal.
Verrouillage général
ID = Developer Portal > ton application > General Information > Application ID. Pour que tout le monde puisse l'ajouter, active « Public Bot » dans l'onglet Bot. Limites Discord : au-delà de 10 serveurs, /creer-serveur ne marche plus ; au-delà de 100, Discord demande de faire vérifier le bot.
